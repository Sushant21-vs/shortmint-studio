# ShortMint Studio v32 — Header controls moved to the right

Only the header alignment changes:
- Settings, credits, Logout, and the account avatar now sit at the far right.
- “SHORTMINT / WORKSPACE” and the current page name stay on the left.
- On small screens, credit and theme controls follow the website’s existing responsive behavior.
- No server, account, login, credit, settings, or editor logic has been modified.

## GitHub update (recommended)
1. Extract `ShortMint_v32_Right_Header_Replace_Only.zip`.
2. In your GitHub project, replace `static/index.html` and `static/shortmint-settings-v30.css` using the files at the same paths inside the ZIP.
3. Commit. Render automatically redeploys if auto-deploy is enabled.
4. Refresh the website with Ctrl+Shift+R if you still see the older alignment.

Use the full project ZIP only when you want to replace the entire repository.
