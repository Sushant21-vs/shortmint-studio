# ShortMint Studio v26 — Cinematic Login

Login page follows the two supplied reference images, implemented as actual responsive HTML/CSS (not a flattened picture). The sign-in, invite registration, admin contact links, password reveal, and global v25 smooth cloud cursor remain connected to existing logic.

## Update GitHub
Replace `static/index.html` and add `static/shortmint-login-cinema-v26.css`. Commit; Render should redeploy. Hard refresh (Ctrl+Shift+R).

The browser address bar and tab cannot be styled by the webpage itself.

**Before redeployment:** download a private account backup from Admin. Render Free has temporary filesystem storage and may lose local SQLite data after restarts/deploys.
