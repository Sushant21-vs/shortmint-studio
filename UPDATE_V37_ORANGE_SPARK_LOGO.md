## Installation
Copy the five files from the Replace Only ZIP into the SAME paths in GitHub:
- static/index.html
- static/shortmint-brand-v37.css (new)
- static/shortmint-spark-logo.png (new)
- static/shortmint-touch-icon.png (new)
- static/favicon.svg

Commit the changes. Render will redeploy the site. Hard refresh with Ctrl+Shift+R if your browser still shows the old icon.
No new dependencies, server API changes, or Render environment variables required.
