02 · CUSTOMIZE

Shorts settings

9:16

Auto Montage stitches multiple short scenes into one edited video with jump cuts. Classic Excerpt and Single Cut still use continuous footage; My Cut List joins your chosen moments.

The engine uses audio activity and visual scene changes to select several moments. Review the video before posting; it does not understand context like a human editor.

Arrange 2–12 moments in the exact order you want. Example: 00:02-00:05 then 00:12-00:16. Each range is cut from the source and assembled into one Short.

Optional hook text displayed on your Short. Captions can be added below.

For center crop, slide toward the person or subject you want to keep visible. Other crop modes ignore this slider.

Paste or upload SRT using timestamps from the original long video. Captions will be trimmed to each exported Short. Auto-transcription is available only when the optional speech-to-text engine is installed.

Export: 9:16 • H.264 MP4 • AAC audio • 30 fps • up to 3 minutes. Processing runs on the host server; higher quality takes longer.
