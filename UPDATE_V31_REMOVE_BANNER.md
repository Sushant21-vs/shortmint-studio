# ShortMint Studio v31 — Remove Dashboard Hero Banner

The large “Make the moment” / phone illustration panel has been removed from the signed-in Dashboard.

The small creator desk label, Creative overview, account statistics, Create New Project, Manage Credits, tips, and project list are preserved. Dashboard spacing is adjusted for desktop and mobile.

Settings from v30, Google login, promos, video export and admin features remain unchanged.

## Fast update from v30

1. Open the **ShortMint_v31_Remove_Banner_Replace_Only.zip** archive.
2. In your GitHub repository, replace these files with the copies in the ZIP:
   - `static/index.html`
   - `static/creator-dashboard-v23.css`
3. Commit to the branch Render deploys (usually main).
4. After redeploy, hard refresh the website (Ctrl + Shift + R) if you see the old banner.

The full GitHub ZIP is also included if you prefer an entire copy.
