# ShortMint v28 — Cinematic Glass Login

## GitHub installation

Replace `static/index.html` and ADD `static/shortmint-cinematic-v28.css`. Keep the rest of the project unchanged. Commit to your existing GitHub repo and let Render redeploy. Hard refresh the browser (Ctrl+Shift+R).

This is a visual-only update. Google sign-in, promo codes, passwords, invite flow, Neon PostgreSQL, credit purchases, and Shorts export are unchanged.

### Visual changes
Responsive cinematic glass card, cream-peach background, orange filmstrip, vertical Shorts phone, glowing SVG cloud trail, scalable vector ribbons, interactive button/focus states and gentle decorative motion.

### Security
Do not change `DATABASE_URL`, `GOOGLE_CLIENT_ID` or owner secrets. Download your private account backup before any production deployment. A Render Free instance still has temporary video storage.
